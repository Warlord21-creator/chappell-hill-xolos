# Chappell Hill Xolos

Static website for **Chappell Hill Xolos** — Xoloitzcuintli raised at home in Chappell Hill, Texas (est. 2014).

## Pages

| File | Description |
|------|-------------|
| `index.html` | Home |
| `available.html` | Waitlist / inquire only (no dog inventory) |
| `gallery.html` | Real kennel photos |
| `about.html` | About, logo seal, historic downtown photo |
| `inquire.html` | Mailto inquiry form |

## Open locally

From this folder (repo root):

```bash
# Option A — open in browser
open index.html          # macOS
xdg-open index.html      # Linux

# Option B — simple local server (recommended)
python3 -m http.server 8080
# then visit http://localhost:8080
```

Or with Node:

```bash
npx serve .
```

## Enable GitHub Pages

1. Open the repo on GitHub: **Settings → Pages**
2. Under **Build and deployment → Source**, choose **Deploy from a branch**
3. Branch: **main** · Folder: **/ (root)**
4. Click **Save**
5. After a minute or two, the site will be at:

   `https://warlord21-creator.github.io/chappell-hill-xolos/`

Custom domain (optional): add it under Pages → Custom domain and point DNS as GitHub instructs.
